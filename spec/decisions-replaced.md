# Replaced decisions

A decision that is no longer true moves here, from `decisions.md`, with the decision that replaces it. It keeps its ID, so a search still finds what it was and why it changed. Nothing in the spec may cite it: the spec check fails on a rule, a question or a decision that still does, and names it, so every place that followed the old decision is looked at again.
